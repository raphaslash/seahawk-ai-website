# Seahawk AI — club website

**Live site: https://seahawkai.github.io/**

Open that link on any device. You do not need GitHub, an account, or any setup just to look at the site.

## What each thing in this folder is

**index.html** — the homepage. Everything you see at seahawkai.github.io comes from this one file.

**club-hub** — the Seahawk Club Hub preview page.

**taste-buddy** — the Taste Buddy app.

**assets** — the logos and photos the site uses.

**_ds** — the design system. The club's colors, fonts, spacing and components. Every page pulls from here so everything matches.

**README.md** — this file. GitHub shows it underneath the file list. It's just a note explaining what the folder is.

**support.js**, **.gitignore**, **.nojekyll** — plumbing. Ignore them.

## Just want to look at something?

Click any file above to read it. Nothing you click here can break the live site.
